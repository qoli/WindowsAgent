# Delegated Pi agent runtime

**Status:** Retired

The Pi integration was removed at the user’s request. WindowsAgent no longer
ships its delegated-task API, PI WEB adapter, component owners, Node runtime
bundle, installer, or client.

Literal foreground-bound keyboard and pointer input remain host-owned
capabilities. Ephemeral Starlark Actions can compose those inputs and
cancellable waits without a Rule. Rule-owned Streaming Actions retain reusable
application workflows and their lifecycle contracts.

This document records retirement only. It is not an installation or operating
contract.
