# Elite Dangerous ship speed text regions

Capture the reviewed `x=1000,y=740,w=260,h=170` region in the centered
1920x1080 reference coordinate space. The resident PP-OCRv6 small DirectML
pipeline returns raw text boxes from the speed-number area. This Action does
not claim that any OCR string is a speed value and does not consult game
journals, `Status.json`, throttle commands, or another data source.
