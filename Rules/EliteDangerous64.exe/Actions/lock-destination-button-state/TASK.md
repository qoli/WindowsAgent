# Read the Lock Destination primary button focus

Read only the fixed primary-action tile on an Elite Dangerous Navigation
detail card in the 1920x1080 reference coordinate space. A high filled HUD
highlight ratio reports `FOCUSED`; an absent fill reports `ABSENT`; the gap is
`UNKNOWN`.

This finite Action does not identify the detail target, distinguish `LOCK
DESTINATION` from `UNLOCK DESTINATION`, send input, or open the Navigation
panel. Those semantics belong to the supervising streaming Action and OCR
evidence.
